Line Follower ADVANCED

Robot line follower 16 sensor dengan gripper, diprogram lewat blok dari browser.

Peserta menyusun strategi lintasan dengan blok berbahasa Indonesia. Kontrol sensor, PID, dan motor sudah tertanam di firmware, jadi robot tetap kencang dan stabil. Tanpa install, tanpa compile, tanpa kabel.

Fitur Utama

Pemrograman Blok

Web app LF Blockly satu file, dibuka langsung di browser. Blok berbahasa Indonesia, mode Simpel dan Advanced, plus simulator lintasan.

16 Sensor Garis

Gripper 2 Servo

Servo angkat dan servo capit untuk misi ambil dan antar barang. Gerak landai dan kalibrasi per robot dari web app.

Encoder + IMU

Blok "maju lurus X cm" dan "putar X derajat" dengan gyro. Kecepatan roda tertutup agar jalan lurus dan konsisten.

Sensor Jarak ToF

Mendeteksi objek di depan robot. Blok pembanding jarak untuk berhenti, menghindar, atau mengambil barang.

Remote HP (Bluetooth)

Aplikasi Android LF Remote: joystick, kendali gripper, tombol STOP, status baterai, dan model 3D yang mengikuti robot.

Layar OLED + 4 Tombol

Menu ikon beranimasi, 5 slot program, kalibrasi, lihat sensor, uji hardware, dan program demo. Semuanya tanpa laptop.

WiFi & USB

Sambung lewat hotspot robot, router kelas, atau kabel USB. Update firmware dari web app tanpa alat tambahan.

Unduhan

Semua file yang dibutuhkan untuk memakai dan memperbarui robot. Diperbarui ….

Riwayat Versi Firmware

Versi sebelumnya (0)

Web app di-build bersama firmware dan dinamai mengikuti versinya. Gunakan web app dengan versi yang sama atau lebih baru dari firmware robot. Daftar versi juga tersedia sebagai manifest.json. Buku panduan pengguna: bagian Panduan.

Cara Memperbarui Robot

Update bisa dilakukan sendiri oleh siswa atau guru, kurang dari satu menit.

DISARANKAN

Lewat Web App (WiFi atau USB)

  1. 1

    Unduh firmware robot (file .bin) versi terbaru dari bagian Unduhan di atas.

  2. 2

    Buka web app lf-blockly.html di Chrome atau Edge, lalu Sambungkan ke robot: pilih WiFi (hotspot robot atau router) atau USB (kabel ke laptop).

  3. 3

    Klik tombol Robot di header web app, buka tab Update, pilih file .bin yang baru diunduh, lalu mulai.

  4. 4

    Tunggu sekitar 30 detik. Layar robot menampilkan progres, lalu robot restart sendiri dengan versi baru. Jangan matikan robot selama proses.

Pastikan baterai robot cukup (di atas 11 V). Bila update gagal di tengah jalan, firmware lama tetap jalan; cukup ulangi. Program yang tersimpan di 5 slot robot tidak hilang saat update.
DARURAT

Flasher USB dari browser

Untuk robot yang tidak bisa menyala normal atau layarnya diam. Colok kabel USB ke laptop, buka halaman flasher di Chrome/Edge, klik Pasang, dan pilih port robot.

Menyambungkan

  1. Nyalakan robot. Layar menampilkan nama LF-xxxx.
  2. Sambungkan laptop ke WiFi LF-Robot-xxxx, password robot1234.
  3. Buka lf-blockly.html, isi alamat 192.168.4.1, klik Sambungkan.
  4. Ingin robot ikut WiFi kelas? Atur dari tombol Robot → WiFi di web app.

Tombol Robot

  [▲]   ┌──────────┐   [✓ OK]
        │   OLED   │
  [▼]   └──────────┘   [← kembali]
  • OK di layar Home = jalankan program aktif.
  • Tombol apa pun saat robot bergerak = STOP.
  • Tahan kembali 3 detik = matikan robot.
  • Tahan ▲ saat menyalakan = Mode Remote (Bluetooth).

Sebelum Lomba

  • ✓Kalibrasi sensor di lintasan yang akan dipakai (menu Kalibrasi, geser robot melintasi garis).
  • ✓Coba program di simulator dulu, lalu upload ke salah satu dari 5 slot.
  • ✓Gunakan checkpoint agar bisa mulai ulang dari tengah lintasan.
  • ✓Baterai penuh (12,6 V). Robot berbunyi tiap menit bila baterai lemah.
  • ✓Mode WiFi dan Mode Remote tidak bisa bersamaan; pilih lewat menu robot.
