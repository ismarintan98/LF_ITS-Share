Flasher USB

Menulis firmware … langsung ke robot lewat kabel USB dari browser. Pakai halaman ini hanya bila robot tidak bisa menyala normal, atau update lewat web app gagal terus. Program siswa di slot robot tetap tersimpan.

  1. 1

    Buka halaman ini di Chrome atau Edge di laptop (Windows, macOS, Linux). Firefox dan HP tidak mendukung.

  2. 2

    Nyalakan robot, lalu colok kabel USB-C robot ke laptop. Tutup aplikasi lain yang memakai port serial.

  3. 3

    Klik Pasang Firmware, pilih port robot (biasanya bertuliskan USB JTAG/serial atau Espressif), lalu pilih Install. Jangan pilih "erase" agar program siswa tidak terhapus.

  4. 4

    Tunggu sampai selesai (±1 menit), lalu cabut-colok kabel atau matikan-nyalakan robot.

Browser ini tidak mendukung Web Serial. Gunakan Chrome atau Edge di laptop. Halaman harus dibuka lewat HTTPS. Unduh file .bin saja

Robot tidak muncul di daftar port? Tahan tombol BOOT di board sambil mencolok kabel, lalu lepas. Linux: pastikan pengguna Anda boleh membuka port serial (grup dialout atau uucp).

Apa yang ditulis? Hanya bagian aplikasi firmware (alamat 0x10000). Bootloader, tabel partisi, pengaturan WiFi, kalibrasi, dan 5 slot program tidak disentuh.
